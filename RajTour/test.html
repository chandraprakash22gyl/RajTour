How it works: Normal state → Only the image is visible. Hover state → The .overlay rotates from 90deg (hidden) to 0deg (visible) like a flip card. Transparent color → Achieved with rgba() so the image is still visible underneath. Smooth animation → Controlled by transition: transform 0.6s ease;. Glass effect → backdrop-filter: blur(4px) for a modern look. 💡 You can change: background-color: rgba(0, 150, 255, 0.4) → to any color & transparency. rotateY → to rotateX if you want a vertical flip instead. transition speed for faster/slower animation.
